## About

I'm a CS undergrad at **VIT Bhopal** (class of 2028) who builds backends, full-stack apps, and applied-ML systems. I'd rather ship a rough MVP and fix it live than polish something nobody uses yet.

- 💼 Open to **Backend / Full-Stack** internships
- 🧠 Interested in system design, applied ML, and software that holds up with real users
- 🌱 Contributing to open source: Cytoscape, Node.js, Zulip, AOSSIE

> **🚧 Building now:** a voice-first system that matches people to government schemes they qualify for and helps them apply. It runs as a 5-stage pipeline, built for a national social-impact hackathon.
